O Simo Ahava comenta as mudanças que o Google lançou como preparação para a integração entre Google Tag e GTM:

- **Novo Overview:** o bloco superior ficou recolhível e as informações viraram uma tabela "Container overview", com resumo do workspace, Google Tags, Container Diagnostics e lista de alterações.
- **Menu lateral recolhível:** em contêineres novos, os recursos avançados ficam atrás de "Show more". O padrão mostra só Overview e Tags. Para o Simo, o foco é o iniciante.
- **Event editor:** pelo "Start guided setup", dá para configurar uma conversão de compra do Google Ads clicando nos elementos do site. Por ora, só para esse caso.
- **A ressalva dele:** usar seletores CSS para um dado tão crítico pode quebrar quando o layout muda. Ele prefere a data layer, com apoio dos desenvolvedores.

## Meu comentário

Quem gerencia contêineres de clientes ou de times mistos deve avisar as pessoas antes de a interface mudar na conta delas. E, se a conversão de compra ainda depende de raspagem da página, vale conversar com o time de desenvolvimento sobre colocar esses dados na data layer.
